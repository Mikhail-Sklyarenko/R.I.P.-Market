# Slice 2 — доверие на inventory (0.6.36)

**Версия расширения:** 0.6.36  
**Дата:** 30 августа 2026  
**Zip:** `browser-extension/rip-market-browser-extension-v0.6.36.zip`

## Что сделано

### T1 — Trade hold
- Баннер на инвентаре Steam: «Часть предметов на Steam trade hold» + счётчик; dismiss на сессию вкладки.
- Бейджи: `Hold · N дн` / `Hold · N ч` вместо `Trade-lock`.
- `Нельзя обменять` / `Нельзя на Steam Market` вместо сырого EN.

### T5 — Sell panel
- Превью: картинка предмета (из Steam DOM) + имя.
- Ориентиры цены: Steam / Рекомендуем (+ «Подставить») / Спрос (bid).
- Honesty: «не мгновенная выплата» — без фейковой «моментальной».

### T3a — Pair vs offline
- Safe-mode баннер в popup **не показывается**, если расширение не подключено (не путаем с «сайт недоступен»).
- Копирайт offline: «Связь с **сервером**/API», а не «сайт лежит».
- Connection strip: «Сайт может быть открыт — Подключить в Аккаунте».

### T4 — CTA
- Primary: **Мои объявления** → `/deals?tab=listings`
- Secondary: **Инвентарь на сайте** → `/sell/inventory`

## Как проверить

| # | Шаг | Ожидание |
|---|-----|----------|
| 1 | Инвентарь с Trade Protected / свежими покупками | Баннер hold; бейджи Hold · N |
| 2 | «Понятно» на баннере → F5 той же вкладки | Баннер скрыт до закрытия вкладки |
| 3 | Синяя «Продать» | Картинка + rails Steam/рекоменд/bid |
| 4 | Popup без pair при открытом p2pcs.ru | Только «Не подключено…», **без** «сайт недоступен» |
| 5 | Host bar connected | «Мои объявления» + «Инвентарь на сайте» |
