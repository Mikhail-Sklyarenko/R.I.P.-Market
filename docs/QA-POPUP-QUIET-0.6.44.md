# QA — Popup quiet redesign 0.6.44

## Продуктовое решение

Popup — не дашборд, а **пульт с одним фокусом**, в визуальном языке p2pcs (`#0b0d12`, cyan→blue primary, elevated surfaces).

### Первый экран

1. **Brand** — R.I.P Market + короткий lead.
2. **Connection** — статус-точка + title + detail (без дубля «Сайт и Steam совпадают»).
3. **Старт (wizard)** — только **текущий** шаг + progress track + одна CTA; «Позже» ghost. Пока wizard открыт — скрыта крупная «Открыть сайт» (CTA у wizard).
4. **Сделки / empty** — как раньше, если есть.
5. **Инструменты** — компактная сетка: Статус / Сделки / отчёт / Отключить.
6. **Pair hint** — только когда не подключено.
7. **Дополнительно** — Состояние (ops health), Доверие (privacy), язык, quiet notify, права, аварийный API key.

## Проверка

1. Load unpacked **0.6.44**, открыть popup.
2. Не подключено: виден compact wizard (один шаг), нет стены из 4 чеклистов; «Открыть сайт» скрыта; hint про pair виден.
3. Подключено + wizard на list: CTA «Выставить первый скин», track показывает прогресс.
4. После «Позже» / complete: появляется primary «Открыть сайт».
5. Ops / privacy только внутри «Дополнительно».
6. Визуально близко к host bar / сайту (градиент CTA, cyan wash).
