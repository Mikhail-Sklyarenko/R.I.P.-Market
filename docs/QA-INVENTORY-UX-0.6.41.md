# QA — extension 0.6.41 (inventory UX polish)

**Zip:** `browser-extension/rip-market-browser-extension-v0.6.41.zip`

## Что изменилось

1. **Host bar на Steam inventory** — под визуальный язык p2pcs.ru:
   - бренд + статус-чип (Подключено / Не подключено / Безопасный режим);
   - человеческий текст вместо «технического» жаргона;
   - кнопки: градиент primary, secondary outline, мультивыбор как отдельный CTA.
2. **Множественная продажа** — в модалке список названий скинов (до 8 + «и ещё N»).
3. Плавающая bulk-панель показывает краткий превью имён.

## Проверка

1. Load unpacked **0.6.41**, обновить вкладку Steam inventory.
2. Host bar: чистый layout, понятный copy, без «Мульти: вкл» / сырого абзаца про Hold/list.
3. Выбрать 2 разных скина → Выставить → в модалке видны **оба названия**.
