# Отчёт для тестировщика — R.I.P Market (пакет за 30–31 августа 2026)

**Версия расширения:** **0.6.38**  
**Сайт (уже обновлён):** https://p2pcs.ru  
**Файл расширения:** `browser-extension/rip-market-browser-extension-v0.6.38.zip`  
**Дата:** 31 августа 2026  

Документ **простыми словами**: что мы исправили и добавили **сегодня**, и как это проверить руками шаг за шагом.

---

## 0. Что нужно перед любым тестом

1. Распаковать zip **v0.6.38** → должна быть папка с файлом `manifest.json`.
2. Chrome → `chrome://extensions` → **Режим разработчика** → **Загрузить распакованное** (или **Обновить**, если уже стояло).
3. Открыть popup расширения → внизу / в блоке здоровья должна быть **Версия 0.6.38**.
4. Войти на **https://p2pcs.ru** тем же профилем Chrome.
5. Аккаунт → **Подключить расширение** (если ещё не подключено).
6. **Обязательно:** после установки/обновления расширения нажать **F5** на вкладках Steam и сайта.  
   Иначе бывает «Extension context invalidated» — это не баг сайта, а старая вкладка.

**Только Google Chrome.** Firefox / Safari не тестируем.

## 1. Одной фразой: что изменилось сегодня

Мы закрыли замечания тестировщика по пути продавца (ложный VAC, localhost, зависания, инвентарь сайта) и добавили **щит сделки (Deal Shield)**: на странице обмена видно, с кем сделка, какой скин и совпадает ли партнёр Steam с заказом.

Сайт и API на **p2pcs.ru** уже задеплоены вместе с этим пакетом.

## 2. Что расширение по-прежнему НЕ делает

| Не делает | Почему |
|-----------|--------|
| Не подтверждает Steam Guard | Только телефон / Steam Mobile |
| Не принимает обмен «само» без вашего клика | Accept только руками (иногда с подсказкой) |
| Не продаёт на Steam Community Market | Зелёная **Sell** справа — это Steam |
| Не снимает все лоты при выключении ПК | Это отдельная идея (пауза продаж) — **ещё не в этом релизе** |

## 3. Список исправлений (замечания тестировщика)

Ниже — ваши прошлые замечания и что сделано.

### 3.1. Аккаунт и подключение

| Было | Стало | Как проверить |
|------|-------|----------------|
| Кнопка «Открыть аккаунт» вела на `localhost:5173` | Всегда открывает **https://p2pcs.ru/account** | Без pair нажать «Открыть аккаунт» в popup / подсказках → должен открыться p2pcs.ru, не localhost |
| Сайт открыт, но путали «не подключено» с «сайт лежит» | Разные тексты: не подключено ≠ offline сервера | Открыть p2pcs.ru **без** pair → popup пишет про подключение, **не** «сайт недоступен» |
| Хотелось быстрее подключить расширение | На сайте синий баннер **одним кликом** «Подключить расширение» | Логин + расширение установлено, но не paired → баннер на сайте → клик → Connect → paired |

### 3.2. VAC и выставление (самые болезненные баги)

| Было | Стало | Как проверить |
|------|-------|----------------|
| Ошибка Steam API выглядела как «у вас VAC» | Три честных кода: реальный VAC / игровой бан / **«не удалось проверить — это не бан»** | При сбое проверки → текст про «не бан» + **Повторить**, **не** «VAC-бан» |
| «Выставить» зависало / сырой `503` / `Extension API failed` | Понятные русские сообщения; при hard ban — «Выставить нельзя» | Попробовать выставить; при ошибке — читаемый русский текст |
| Новый аккаунт: «Обновить из Steam» → FORBIDDEN | Обновление инвентаря доступно без SELLER-only gate | Новый BUYER со Steam → `/sell/inventory` → **Обновить из Steam** → нет FORBIDDEN |

### 3.3. Trade hold и модалка продажи в Steam

| Было | Стало | Как проверить |
|------|-------|----------------|
| Непонятно, что предметы на hold | Баннер «часть на Steam trade hold» + бейджи `Hold · N дн/ч` | Инвентарь со свежими покупками / Trade Protected → баннер и бейджи |
| В «Продать» не было картинки / ориентиров цены | Есть превью скина + Steam / рекомендуем / спрос; **без** вранья про «мгновенную выплату» | Синяя «Продать» → картинка + rails цен |
| CTA «Мои продажи» вела не туда | **Мои объявления** → `/deals?tab=listings` | Host bar → «Мои объявления» |

### 3.4. Сайт: инвентарь не грузится / скелетоны

| Было | Стало | Как проверить |
|------|-------|----------------|
| Сайт не мог загрузить инвентарь (Steam блокирует сервер) | Баннер **«Выставить из Steam-инвентаря»** + кнопка в CS2 inventory | `/sell/inventory` при ошибке/«УСТАРЕЛО»/долгой загрузке → баннер и CTA в Steam |
| Ошибка на одном лоте «липла» на другой | Смена предмета сбрасывает ошибку и «Публикация…» | Открыть лот A → ошибка → открыть лот B → чистое окно |

### 3.5. Черновик, средняя цена, помощь сайту из вкладки Steam

| Было | Стало | Как проверить |
|------|-------|----------------|
| F5 сбрасывал выбор и цену | Черновик в **той же** вкладке восстанавливается | Bulk-выбор + цена → F5 → chip «Восстановлено» |
| Не было честной «средней» Steam | Если Steam отдал median — строка **Средняя Steam** (не выдумываем 7 дней) | Предмет с median ≠ lowest → видна средняя |
| Сайт пустой из‑за Steam block | Кнопка **«Обновить сайт из вкладки»** шлёт снимок инвентаря на сервер | При пустом сайте → Steam inventory → «Обновить сайт из вкладки» → предметы появляются на сайте |

## 4. Новое: щит сделки (Deal Shield) — версия 0.6.38

Это **главная новая фича** сегодня для безопасности обмена.

### Что увидит пользователь

На странице Steam `tradeoffer/…` (и в деталях списка офферов / в popup / на странице заказа на сайте):

1. **С кем сделка** — Продавец или Покупатель, аватар, ник, SteamID, кнопка копировать, ссылка на профиль.
2. **Какой заказ** — короткий номер и цена.
3. **Какой скин** — картинка, название; износ / float / стикеры — **только если они есть** (пустые строки не рисуем).
4. **Сверка с Steam** — таблица «ожидаем / в оффере», включая **SteamID партнёра**.
5. Если партнёр **не совпадает** → красный статус, **не принимать**, ссылка на спор. Accept-подсказка не предлагается.
6. Для продавца на странице **нового** обмена (`tradeoffer/new`) — блок **«Перед отправкой»**: проверьте покупателя и предмет.

Расширение **по-прежнему никогда само** не жмёт Accept.

## 5. Подробные сценарии тестирования

Делайте по порядку. В конце каждого — **Pass / Fail** + скрин при Fail.

---

### Сценарий A — установка и pair (5 минут)

1. Установить zip **0.6.38**, F5 на Steam/сайте.  
2. Popup → версия **0.6.38**.  
3. p2pcs.ru → Аккаунт → Подключить расширение.  
4. Popup: зелёная связь, «Сайт и Steam совпадают» (или понятная ошибка, если Steam другой).

**Ок:** подключилось, версия верная.  
**Плохо:** localhost, старая версия, вечный «переподключить».

---

### Сценарий B — «Открыть аккаунт» без pair

1. Отключить расширение на сайте (или свежий профиль без pair).  
2. Найти CTA «Открыть аккаунт» / pair hint.  
3. Клик.

**Ок:** открывается `https://p2pcs.ru/account`.  
**Плохо:** `localhost:5173` / connection refused.

---

### Сценарий C — one-gesture pair на сайте

1. Расширение установлено, на сайте **не** paired.  
2. Открыть любую страницу p2pcs.ru (не Account).  
3. Должен быть баннер «Подключить расширение».  
4. Один клик → Connect → paired.

**Ок:** после клика popup зелёный.  
**Плохо:** silent pair без клика (так не должно быть) или баннер не появляется.

---

### Сценарий D — выставление из Steam (продавец)

1. CS2 inventory (`#730_2` или актуальный контекст).  
2. Синяя полоска R.I.P + синие **«Продать»** на ячейках.  
3. Выставить tradable скин по адекватной цене.  
4. Успех → лот на сайте / «Мои объявления».

**Ок:** выставилось, сообщения по-русски.  
**Плохо:** сырой английский API error, зависание «Выставляем…», ложный VAC.

**Дополнительно (hold):** если есть trade hold — баннер и бейджи Hold.

**Дополнительно (черновик):** выбрать 2–3 предмета / ввести цену → F5 → восстановилось. Закрыть вкладку полностью → черновика нет.

---

### Сценарий E — сайт не грузит инвентарь

1. `/sell/inventory` в ситуации пусто / ошибка / «УСТАРЕЛО» / долгая загрузка.  
2. Баннер со Steam CTA.  
3. Открыть Steam inventory.  
4. На host bar: **«Обновить сайт из вкладки»** (нужен pair).  
5. Вернуться на сайт — предметы есть (или toast с числом).

**Ок:** есть выход в Steam и/или sync из вкладки.  
**Плохо:** бесконечные скелетоны без кнопок.

---

### Сценарий F — модалка на сайте не «липнет»

1. `/sell/inventory` → открыть предмет A → добиться ошибки list (или отменить).  
2. Сразу открыть предмет B.

**Ок:** на B нет чужой ошибки и нет залипшего «Публикация…».  
**Плохо:** ошибка A на экране B.

---

### Сценарий G — сделка end-to-end + щит (главный)

Нужны два Steam: продавец и покупатель + баланс покупателя на staging.

1. Продавец: pair, Trade URL, выставить скин (из Steam или сайта).  
2. Покупатель: купить лот на p2pcs.ru.  
3. Продавец: расширение шлёт trade offer; Guard — только в телефоне.  
4. Покупатель: открыть оффер из popup / заказа.  
5. На странице offer проверить **щит**:
   - аватар продавца;
   - SteamID продавца (скопировать);
   - название скина, заказ #, цена;
   - сверка «ожидаем / в оффере»;
   - статус совпал → можно принимать кнопкой Steam (с подсказкой расширения, если есть).  
6. Accept **вручную** в Steam (двойное подтверждение подсказки — ок).  
7. На странице заказа на сайте — карточка продавца/покупателя с аватаром и характеристиками скина (если есть).

**Ок:** оффер один, щит понятный, Accept не сам.  
**Плохо:** щит пустой, Accept без клика, фазы заказа не двигаются.

---

### Сценарий H — щит при несовпадении партнёра

1. Дойти до страницы offer покупателя (как в G).  
2. Если удаётся открыть **чужой** / несвязанный offer — панель «Не наша сделка».  
3. Если партнёр Steam не совпадает с заказом — красный mismatch, Accept assist нет, есть путь в спор/заказ.

**Ок:** система говорит «не принимайте».  
**Плохо:** зелёный «совпало» на чужом оффере.

---

### Сценарий I — продавец перед отправкой (pre-send)

1. Продавец в состоянии «нужно отправить оффер» (после покупки).  
2. Открыть Trade URL покупателя (`tradeoffer/new/?partner=…`).  
3. Должен быть баннер **«Перед отправкой»** + покупатель + предмет + сверка.

**Ок:** видно, кому и что отправляете.  
**Плохо:** пустая страница без щита при активной продаже.

---

### Сценарий J — popup после сделки

1. Во время/после активной сделки открыть popup.  
2. В покупках/продажах — полоска с аватаром контрагента и краткими характеристиками (если есть).  
3. Один главный CTA на карточке («Подтвердите Guard» / «Открыть оффер» и т.д.).

**Ок:** понятно, что делать дальше.  
**Плохо:** пустые карточки / два равнозначных главных действия.

## 6. Что сознательно НЕ входит в этот пакет

- Автоснятие всех объявлений при выключении ПК / расширения (будет отдельная «пауза продаж»).  
- Полный архив всех старых сделок только внутри popup (есть недавние квитанции + сайт).  
- Тихий auto-pair без клика.  
- Фраза «мгновенная выплата», если settlement ещё не такой.  
- Черновик продажи после **полного** закрытия вкладки Steam.

Если найдёте баг из этого списка — отметьте как **Out of scope**, не Fail релиза 0.6.38.

5. Что нажали и что ожидали.

## 10. Итог

Пакет **0.6.38** + сайт **p2pcs.ru** — для приёмки:

1. продавец может выставлять **без вранья про VAC и localhost**;  
2. при проблемах Steam у сайта есть путь через **инвентарь Steam**;  
3. в момент обмена покупатель/продавец видят **щит сделки** (кто, что, сверка);  
4. Accept / Guard — только руками человека.

Главное при приёмке: версия **0.6.38**, после установки всегда **F5**, сценарии **G** и **D** обязательны.
